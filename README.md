MATLAB-based framework for single-cell migration tracking and quantitative analysis of time-lapse microscopy data, including migration speed, net displacement, accumulated distance, directional persistence, and trajectory visualization in cancer mechanobiology studies.

Single-Cell Migration Analytics

Project Overview
A MATLAB-based computational framework for quantitative 
analysis and visualization of single-cell migration data 
derived from time-lapse microscopy.

Key Features
- Single-cell trajectory visualization
- Migration velocity analysis
- Net displacement quantification
- Accumulated migration distance
- Directional persistence analysis
- Comparative cell motility analysis

Technical Skills
MATLAB | Scientific Computing | Biomedical Data Analytics |
Quantitative Image Analysis | Data Visualization |
Computational Biology

Applications
Cancer research, cellular mechanobiology, quantitative
biology, and biotechnology R&D.
