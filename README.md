# Single-Cell Migration Analytics

## Project Overview

A MATLAB-based computational framework for quantitative analysis and visualization of single-cell migration data derived from time-lapse microscopy.

## Representative Output

![Single-Cell Migration Analysis](track%20plot.png)

## Key Features

- Single-cell trajectory visualization
- Migration velocity analysis
- Net displacement quantification
- Accumulated distance analysis
- Directional persistence analysis
- Comparative cell motility analysis

## Technical Skills

- MATLAB programming
- Biomedical data analytics
- Scientific computing
- Quantitative image analysis
- Data visualization
- Computational biology

## Applications

Cancer research, mechanobiology, biotechnology R&D, and quantitative cell biology.
